## ✨ About the Project

A modern full-stack e-commerce platform built with Next.js that delivers a fast, responsive, and secure shopping experience. The application allows customers to browse products, search by category, manage their cart, and place orders, while providing an intuitive admin dashboard for managing products, categories, users, and orders.

## ✨ Features

### Customer

* Responsive shopping experience
* Product browsing
* Product search
* Category filtering
* Product details page
* Shopping cart
* Secure authentication
* User registration & login
* User profile
* Order placement
* Order history
* Smooth GSAP animations

### Admin Dashboard

* Dashboard overview
* Product management
* Category management
* User management
* Order management
* Product image upload with Cloudinary
* Search and filtering
* Inventory management

### Security

* JSON Web Token (JWT) authentication
* JOSE token verification
* Password hashing with bcrypt
* Protected routes
* Secure API endpoints
